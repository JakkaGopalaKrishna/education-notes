## Question 6: Write about the book's perspective on how to make a habit easier to do?

According to the book, use the 2-Minute Rule and reduce friction:

Ways to make habits easier:
- Make it obvious.
- Make it attractive.
- Make it easy.

Examples:
- Use a habit tracker to make it satisfying.
- Use a calendar to mark off days you complete the habit.
- Reward yourself with a small treat after completing the habit.
---

## Question 7: Write about the book's perspective on how to make a habit harder to do?

To break bad habits:
- Make it hard.
- Make it unsatisfying.

Examples:
- Keep phone in another room.
- Use a password to add friction to unwanted behaviors.

## Question 8: Pick one habit that you would like to do more of? What are the steps that you can take to make it make the cue obvious or the habit more attractive or easy and or response satisfying?

**One habit I want to do more of: Daily Coding Practice**

I want to code consistently every day to improve as a MERN stack developer.

- **Make Cue Obvious**:  
  - Set reminders on phone.  
  - Keep laptop ready on desk.
  
- **Make It Attractive**: 
  - Join a coding community for motivation.
  - Follow coding influencers on social media for inspiration.

- **Make It Easy**:  
  - Start with just 10 minutes.
  - Use online coding platforms with guided exercises.

- **Make It Satisfying**:  
  - Celebrate small wins and push code to GitHub daily.
  - Share my progress with friends or mentors for encouragement.

---

## Question 9: Pick one habit that you would like to eliminate or do less of? What are the steps that you can take to make it make the cue invisible or the process unattractive or hard or the response unsatisfying?

**One habit I want to reduce: Excessive scrolling on your phone before bed**

- **Make Cue Invisible**:  
  - Keep phone out of reach at night.
  - Use a traditional alarm clock instead of phone. 

- **Make It Unattractive**:  
  - Track wasted time weekly.
  - Remind myself of lost productivity.

- **Make It Hard**:  
  - Use app blockers.
  - Set a strict bedtime routine without screens.

- **Make It Unsatisfying**:  
  - Reflect on how it affects sleep quality.
  - Reward myself with a relaxing activity instead of scrolling.
