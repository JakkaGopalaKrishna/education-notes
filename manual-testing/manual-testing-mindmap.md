## Important Testing Types
| Type                  | Purpose                                     |
| --------------------- | ------------------------------------------- |
| Smoke Testing         | Checks basic functionality                  |
| Sanity Testing        | Checks specific functionality after changes |
| Regression Testing    | Ensures old features still work             |
| Retesting             | Rechecks fixed bugs                         |
| Integration Testing   | Checks module interaction                   |
| System Testing        | Tests complete application                  |
| UAT Testing           | Validates business requirements             |
| Performance Testing   | Checks speed and stability                  |
| Security Testing      | Checks vulnerabilities                      |
| UI Testing            | Checks user interface                       |
| Compatibility Testing | Checks browser/device support               |
